
# ER. T. SABARIKANNAN Construction & Interiors

A professional construction and interior design website based in Madurai, Tamil Nadu.

## About the Project

This website is developed to showcase construction and interior design services, completed projects, and company information.

Our goal is to help customers explore our services and connect with us easily for their construction and interior requirements.

## Website Features

- Home Page
- About Us
- Projects Gallery
- Services Page
- Contact Page
- WhatsApp Contact Integration
- Responsive Website Design
- Admin Dashboard

## Technology Stack

- Frontend: React.js
- Build Tool: Vite
- Routing: React Router
- Backend / Database: Supabase
- Hosting & Deployment: Cloudflare Pages
- Version Control: GitHub

## Website Design

The website uses a clean beige-and-white colour theme with a modern and professional layout.

## Service Locations

- Madurai

- Pudukkottai
- Trichy
- Virudhunagar

## Deployment

The project is connected to GitHub and deployed using Cloudflare Pages.

New changes pushed to the connected GitHub branch can trigger a new deployment.
